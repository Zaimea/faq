## About Zaimea

### What is Zaimea?
Zaimea is a technology company focused on building practical tools that simplify complex workflows. We offer:
- **Zaimea Groups**: A comprehensive time tracking and team management platform
- **Open Source Packages**: Collection of PHP/Laravel packages for developers
- **Custom Development**: Tailored solutions for specific business needs

### Who is behind Zaimea?
Zaimea was founded by developers who wanted to create tools they needed themselves. What started as personal projects evolved into products used by teams worldwide. We believe in building software that grows with our users.

### What does "Zaimea" mean?
"Zaimea" represents our philosophy of creating tools that help you "seize your day" (a play on "carpe diem"). We build software that helps teams work more efficiently and focus on what matters.

## Products & Services

### What products does Zaimea offer?
We offer three main categories of products:

| Product | Description | Best For |
|---------|-------------|----------|
| **Zaimea Groups** | Time tracking, project management, team collaboration | Teams needing work hour management |
| **Open Source Packages** | Laravel/PHP packages (Charts, PDF, Metrics, etc.) | Developers building web applications |
| **Custom Development** | Tailored software solutions | Businesses with specific workflow needs |

### What's the difference between Zaimea Groups and other time tracking tools?
Zaimea Groups stands out because:
- **Progressive Development**: We continuously add features based on user feedback
- **Flexible Group System**: Work with multiple teams/companies in one account
- **Granular Permissions**: Detailed role system with custom permissions
- **Plugin Architecture**: Enable only the features you need
- **No Vendor Lock-in**: Export your data anytime

### What open source packages do you offer?
We maintain several popular Laravel packages:
- **Charts**: Interactive data visualization
- **PDF Generation**: Create and export PDF documents
- **Metrics**: Track and display key metrics
- **Socialite**: Social authentication extensions
- **Heroicons**: Blade components for Heroicons
- **Search**: Advanced search capabilities
- **And more**... [Browse all packages](/docs)

### Do you offer custom development services?
Yes! We work with businesses to build custom solutions:
- **Workflow Automation**: Streamline business processes
- **Integration Development**: Connect existing systems
- **Custom Features**: Extend Zaimea Groups for specific needs
- **Complete Applications**: Build from scratch solutions

> {tip} Contact us at [developers@zaimea.com](mailto:developers@zaimea.com) to discuss your project.

### How do I create an account?
You can create different types of accounts:

1. **Zaimea Groups Account**: [Register here](route('groups.register'))

### Is Zaimea Groups really free?
We offer a **free forever plan** with:

- 1 group
- 5 projects

## Open Source

### Are all Zaimea products open source?
We have a mixed approach:
- **Open Source**: All our Laravel/PHP packages are MIT licensed
- **Source Available**: Zaimea Groups code is not open source
- **Commercial**: Custom development and Enterprise features

### Can I self-host Zaimea Groups?
Currently, Zaimea Groups is only available as a hosted SaaS solution. Self-hosting is being considered for future Enterprise plans.

### How do I report security vulnerabilities?
Please report security issues to [security@zaimea.com](mailto:security@zaimea.com). We run a bug bounty program with rewards for critical vulnerabilities.

### Do you accept pull requests?
Absolutely! We welcome PRs for:
- Open source packages
- Documentation improvements
- Translation updates
- Bug fixes

Check our [Contributing Guidelines](route('docs', ['package' => 'open-source', 'version' => 'main', 'page' => 'contributions'])) for details.
